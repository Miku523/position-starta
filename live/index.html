这是部署在 GitHub Pages 上的只读快照。GitHub Pages 只托管静态文件，不执行 Node.js， 所以在线地址不会建立 SSE 连接；本机启动 source/live/server.js 后，同一个界面会变成实时版。

为什么不是实时？

实时大屏依赖 Node 服务端（SSE + /live/event 写入）。线上页面没有服务端，因此这里展示最近一次快照； 本机运行服务后，大屏、工作台和报告页的实时胶囊都会重新连上。数字口径与 /live/health 一致： 会话台账跳过「合计」行，29 次提交 = 4 个批次之和。

本机查看实时版

cd 提交包
node source/live/server.js --root . --port 8790
# 浏览器打开 http://127.0.0.1:8790/live/

零依赖，Node ≥ 18 即可；SSE 不可用时组件自动降级为「未连服务」，不会阻塞页面。
