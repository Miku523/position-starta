门槛不写在“技能”里

学历是硬筛，专业是软筛。9,200 个岗位里 72.6% 卡本科、14.6% 卡硕士、4.5% 卡博士；而「专业不限」一个都没有——每个岗位都写了专业。顺序本身就是权重。（E-01 / E-02）

真正的稀缺在交叉处

专业榜前四名里两个是教师方向：「学科教学硕士」1,414 +「课程与教学论」919，合计 2,333 个岗位（25.4%）；紧随其后的是临床医学 808、会计学 771。地区榜第一是湛江，不是广州。读专业榜，读到的是产业结构，不是偏好。（E-01 / E-02）

03 / SAMPLING怎么采的，以及哪里没采到
03 — Sampling

采样方案：为什么是这 19 个地址

不抓商业招聘平台（反爬风控与合规都不适合公开演示），只抓公开但难抓的源：政府公告、事业单位招聘详情页、挂 xlsx／pdf 附件的通知。它们共同的特征是——页面要靠浏览器渲染、附件藏在链接里、同一台服务器时好时坏。

源地址为什么选它拿到什么

未采到 · 9 次尝试
没采到的部分比采到的更需要交代
  • hrss.gd.gov.cn 的招聘列表页：navigation timeout，连试 4 次都没开。
  • 同一份公告（post_4848983）：提交 6 次，成功 2 次、失败 4 次——一次是建会话时 HTTP error，三次是导航超时。
  • hrss.gd.gov.cn 的另外两个详情页：同样超时；浙江那页能开但抓不到岗位。

所以真实账目是：19 个唯一地址，29 次提交尝试，20 次成功。同一页反复失败不是重试没用，是那台服务器对学生时段以外的访问不稳定——这件事只能写出来，不能藏。

同一套字段，吃两种源

两类源的表头完全不同：一边是 xlsx 里的「考区／单位代码／岗位代码」，一边是 PDF 里的「序号 / 单位／岗 位／学历要求」。归一器把它们映射到同一套 11 个字段，于是可以并排放进一张表。

06 / ACTION数据不落地，就只是表
06 — Action & Recipe

行动：这张表能改写三个判断

表本身不是成果。9,200 行真数据至少能改掉三个凭直觉会做错的判断——每一条都给出反直觉的差值。

凭直觉 · 会这么想
  • 「广州机会最多，当然先投广州」
  • 「事业单位就是行政岗，跟专业没什么关系」
  • 「本科学历已经把大部分人筛掉了」
数据 · 实际是这样
  • 广州只有 546 个岗位（5.9%），湛江 1,320（14.3%）、梅州 1,059（11.5%）——重心在粤东西北
  • 不是「行政一条街」：学科教学硕士（1,414）＋课程与教学论（919）＝25.4% 是教师岗，但紧跟着的就是临床医学（808）与会计学（771）
  • 72.6% 就卡在本科，本科不是过线而是主力；硕士 14.6%、博士 4.5%

可复用：一份配方，换个站点就能跑

七个字段，改三行就能换一个行业。它不是工具，是一份可被检验的采样方案。

方法局限 · 这份报告不能证明什么A-03 +
9,200 个岗位里 9,169 条来自同一份省级岗位表的 5 张 sheet，另 31 条来自国家林草局的一份 PDF，不是全省全行业，更不是全市场；专业写法不统一（“学科教学硕士（专业硕士）”与简称混用），做合并时会有误判；只覆盖 2026-10-20 一次快照，不能当趋势看；xlsx 靠文本解析列，版式一换就可能错列——这次就踩过空单元格导致整体左移。另外，专业榜的计数口径这次改过：旧脚本按「单元格出现次数」记，一个岗位在大专／本科／研究生三列里都写了「会计学」就算 3 票；现在改成「每个岗位对每个专业只记 1 票」。会计学因此从 1,241 降到 771，靠前的排序也跟着变——数字变化主要来自这条口径修正，不是那 31 行的加入。
复现步骤 · 想自己跑一遍A-04 +
1 · 起采集台
在 recruit-tool/ 里跑 node server.js，开 http://127.0.0.1:8901。引擎选「Lexmount 云浏览器」，贴公告详情页地址，必要时勾「列表页展开详情」再点开始。凭证走环境变量（LEXMOUNT_API_KEY / LEXMOUNT_PROJECT_ID / LEXMOUNT_BASE_URL），每个 Session 跑完都显式 close，不挂账。
2 · 归一成同一套字段
跑完在「汇总表」点「归一为统一表」：不同公告的 xlsx / PDF 表头会被映射到 11 个字段。要跨批次聚合就去「历史记录」勾几份 → 合并选中。
3 · 重算统计
批次会落到 runs/batch-*.json，然后跑 python canon_stat.py runs/batch-1792437271749.json，输出学历构成、专业频次、地区分布、单位数、聘用人数合计。
4 · 看报告
strata-report/index.html 是单文件，双击就能开；要截图或打印就 python -m http.server 8899 起个本地服务再访问。
环境依赖：Node 22+；.doc 转 .docx 需要 LibreOffice；PDF 用 bin/pdftotext/pdftotext.exe（已随工具打包，含三个 DLL）；xlsx 只用 tar 解包 + XML 解析，不依赖 Office。
